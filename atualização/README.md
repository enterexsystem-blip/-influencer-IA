# Pasta de atualização da Ayla

Coloque aqui os arquivos ZIP com novas versões dos áudios da Ayla.

Quando você enviar uma atualização, os ZIPs devem ser revisados e extraídos; não deixe o ZIP como se fosse um áudio pronto para o bot. Os áudios organizados serão movidos para as pastas corretas da biblioteca `media/audios/`.

Esta pasta é apenas a caixa de entrada para atualizações. Não apague nem substitua a biblioteca antiga antes de conferir a nova versão.
