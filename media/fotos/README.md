# Fotos da Ayla

Organize as fotos em subpastas por categoria (por exemplo, perfil, selfies, looks e atividades). Registre uma descrição curta, tags e condições de uso de cada arquivo.

Não coloque dados privados, credenciais ou imagens de terceiros sem autorização. Arquivos de mídia ainda precisam ser enviados separadamente; este README não significa que fotos já estejam carregadas.
