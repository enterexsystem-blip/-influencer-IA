## Convenção de nomes
Use nomes em minúsculas, sem espaços ou acentos, por exemplo `acabei_dormindo.mp3`.

Para cada áudio, registrar: caminho, transcrição exata, intenção, emoção, destinatário permitido (`todos` ou `kyodai`), tags e observações. A regra de destinatário deve ser validada no código também; não confiar só na pasta.

Os áudios enviados no chat ainda precisam ser copiados como arquivos binários para o repositório ou para um armazenamento de mídia. Os arquivos README criam a estrutura, mas não contêm os MP3.
