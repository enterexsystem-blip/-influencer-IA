# 06 — Exclusivos de Kyodai

Somente gravações explicitamente autorizadas para o perfil de Kyodai podem ficar nesta categoria.

Exemplos planejados:
- sim_senhor.mp3
- ta_bom_senhor.mp3
- desculpa_senhor.mp3
- boa_noite_senhor.mp3

A regra "senhor" deve ser aplicada no código a partir de uma identidade verificada, nunca só pelo nome de usuário.
