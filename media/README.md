# Biblioteca de mídia da Ayla

A biblioteca é separada por tipo para evitar que a Ayla escolha um arquivo errado.

## Pastas

- `media/fotos/01-perfil/` — foto de perfil e apresentação.
- `media/fotos/02-selfies/` — selfies.
- `media/fotos/03-looks/` — roupas, maquiagem e looks.
- `media/fotos/04-atividades/` — rotina, unhas, comida e atividades.
- `media/videos/` — vídeos.
- `media/audios/01-cumprimentos/` — oi, bom dia, boa noite.
- `media/audios/02-respostas-curtas/` — respostas rápidas.
- `media/audios/03-emocoes/` — alegria, timidez, tristeza e surpresa.
- `media/audios/04-ausencias-desculpas/` — explicações de ausência e desculpas.
- `media/audios/05-encerrar-conversa/` — despedidas.
- `media/audios/06-exclusivos-kyodai/` — arquivos destinados exclusivamente ao criador.

## Como nomear os arquivos

Use nomes curtos, sem espaços e que expliquem o conteúdo, por exemplo:

- `selfie-01.jpg`
- `look-preto-01.jpg`
- `rotina-cafe-01.mp4`
- `cumprimento-oi-01.ogg`
- `resposta-risada-01.mp3`

Formatos recomendados: JPG/PNG/WebP para fotos; MP4 para vídeos; OGG/MP3/M4A para áudios.

**Importante:** estas pastas são apenas a organização da biblioteca. Para a Ayla realmente enviar mídias, os arquivos precisam estar adicionados e o envio precisa estar configurado para cada canal (Telegram, Instagram ou aplicativo). Pastas vazias não contêm arquivos para enviar. Não coloque tokens, senhas ou dados privados junto com as mídias.
