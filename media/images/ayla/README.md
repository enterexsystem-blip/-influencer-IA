# Biblioteca visual da Ayla

- `perfil/`: candidatas para foto de perfil
- `fotos-dela/`: retratos pessoais
- `atividades/`: o que ela está fazendo
- `comida/`: refeições e lanches
- `looks/`: roupas, beleza e estilo
- `vip/`: álbum sensual da personagem adulta fictícia
- `capa/`: capas e fundos

Arquivos recebidos depois podem ser adicionados às pastas correspondentes. O Telegram Bot API não permite ao bot alterar a própria foto de perfil; isso precisa ser feito pelo BotFather.
